# Publication scope

The source inventory was reviewed across application folders and archived source variants. Canonical working source was selected where old releases or exports were duplicates. Binary-only tools, private data, installers, operating-system folders, customer specifications, contracts, downloaded third-party packages, and design-only drafts are not presented as completed software products.

Fresh public source histories keep the collection small and avoid inheriting private historical content. Each staged edition was scanned for secrets before publication. Real databases, environment credentials, uploads, personal documents, large models and generated results are excluded. Small lockfiles, build manifests, migrations and actual implementation source are retained when needed for review.

No tests, builds, applications, live service integrations or hardware sessions were run for this batch. Static source/privacy review and Git publication checks are separate from product validation. Corrections restored runtime source files that generic filters initially omitted. The LMS edition explicitly identifies original NUL-corrupt modules rather than implying complete recoverable source.

Original D: working trees, changes and remotes remain untouched. The edition-specific license and third-party notices remain authoritative; this catalogue does not grant additional rights over the linked code.
