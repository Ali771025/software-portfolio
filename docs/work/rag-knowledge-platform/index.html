دستیار دانش سازمانی

بررسی نمونه‌کار دستیار دانش سازمانی از یوسف عمرانی: مسئله، ساختار سورس، فناوری‌ها و حدود نسخه عمومی.

Python · FastAPI · React · TypeScript

مسئله و زمینه

پرسش از مجموعه اسناد به مسیر آماده‌سازی، بازیابی و گفت‌وگو نیاز دارد. این نمونه مسئولیت‌های backend و frontend را برای گردش دانش مبتنی بر سند جدا می‌کند.

آنچه در سورس دیده می‌شود

  • ماژول‌های ingestion و retrieval برای آماده‌سازی و بازیابی
  • مسیرهای دانش گرافی و حافظه گفت‌وگو در backend
  • سازمان‌دهی workspace، feature و state در رابط React
  • نقاط توسعه برای ارائه‌دهنده مدل، دیتابیس و کارهای پس‌زمینه

نمودار معماری سورس؛ تصویر اجرای محصول نیست

حدود نسخه و شواهد

نتیجه پاسخ مدل، میزان بازیابی و حفظ محرمانگی در محیط مشتری نیازمند ارزیابی و پیکربندی مستقل است. داده واقعی و کلید سرویس در این سورس عمومی وجود ندارد.

کاربرد برای یک پروژه مشابه

برای تعیین دامنه دستیار دانش داخلی، اتصال اسناد و طراحی مسیر ارجاع به منبع می‌توان این ساختار را بررسی کرد.
