مدیریت قرارداد دسکتاپ

بررسی نمونه‌کار مدیریت قرارداد دسکتاپ از یوسف عمرانی: مسئله، ساختار سورس، فناوری‌ها و حدود نسخه عمومی.

C# · .NET 8 · WPF · MVVM · EF Core · SQLite

مسئله و زمینه

چرخه قرارداد شامل طرف‌ها، پرداخت‌ها، دریافت‌ها و ضمانت‌هاست و به فرم، گزارش و ثبت تغییرات نیاز دارد. این نمونه، پیاده‌سازی دسکتاپ ویندوز با لایه‌های جدا را نشان می‌دهد.

آنچه در سورس دیده می‌شود

  • مدل‌های Domain و Application برای گردش قرارداد و عملیات مالی
  • رابط WPF با MVVM و جهت فارسی RTL
  • EF Core و مسیرهای persistence و migration
  • ابزارهای مهاجرت و abstractionهای مجوز و ثبت رخداد

نمودار معماری سورس؛ تصویر اجرای محصول نیست

حدود نسخه و شواهد

قرارداد و دیتابیس واقعی حذف شده‌اند. بازگردانی وابستگی‌ها، مسیرهای داده و نیازهای dashboard باید پیش از اجرای محلی بررسی شوند؛ پذیرش نسخه عملیاتی ادعا نمی‌شود.

کاربرد برای یک پروژه مشابه

نقطه شروع برای نرم‌افزار مدیریت قرارداد و بازطراحی گردش‌های قدیمی Access با دامنه و مهاجرت توافق‌شده.
