مسئله و زمینه

ساخت یک محیط گزارش‌سازی متصل به هوش مصنوعی، نیازمند جداسازی قواعد کاربرد، سرویس‌ها و رابط پرس‌وجو است. این نمونه ساختار بک‌اند .NET و محیط React مرتبط را ارائه می‌کند.

آنچه در سورس دیده می‌شود

  • جداسازی Domain و Application از Infrastructure و API
  • قراردادها و interfaceهای گردش پرس‌وجوی هوشمند
  • کارگر پس‌زمینه در کنار API
  • محیط مرورگری React و TypeScript برای پرس‌وجو
