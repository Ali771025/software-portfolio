مسئله‌ای که می‌توانیم بررسی کنیم

وقتی اطلاعات پرونده‌ها، فرم‌ها و قراردادها در چند فایل و ابزار پخش شده، پیگیری کار و دسترسی به نسخه درست دشوار می‌شود. می‌توانیم گردش فعلی را بررسی و یک مسیر روشن برای ثبت، جست‌وجو، گزارش و دسترسی کاربران طراحی کنیم.

دامنه‌های قابل توافق

  • مدل‌سازی فرایند، نقش کاربران و فرم‌ها پیش از توسعه
  • پیاده‌سازی API و رابط وب فارسی یا نرم‌افزار دسکتاپ ویندوز
  • طراحی مسیر گزارش، نسخه‌بندی سند و پردازش پس‌زمینه در دامنه توافق‌شده
  • بررسی مهاجرت اطلاعات موجود و اتصال به سرویس‌های فعلی
