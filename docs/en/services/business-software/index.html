The workflow we can scope

Records spread across spreadsheets, folders and separate tools make it difficult to track work and locate the right version. We can map the existing process and scope a focused application for records, search, reporting and user access.

Possible project scope

  • Map processes, user roles and forms before implementation
  • Build an API and a Persian-first web interface or Windows desktop application
  • Scope reporting, document versions and background processing
  • Review existing data migration and integration requirements

What helps scope the work?

Share the workflow, a non-confidential input/output example, user roles, deployment environment and required integrations. Timing and cost can be agreed once the scope is understood.
